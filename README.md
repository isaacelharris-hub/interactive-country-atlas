
# Visualize AI

An AI visual canvas where users can chat with an AI and have responses visualized on the main canvas.

## Features

- AI chat interface
- Visual canvas
- Technical diagrams
- AI-generated visual specifications
- Session-only BYOK API key
- Effort control
- Creativity control
- Visual-detail control
- Multiple canvas styles
- Grid modes
- Animation controls
- Dark/light/system themes
- Presets
- Conversation history
- Canvas export
- Keyboard shortcuts
- Responsive interface

## Important security note

This version is designed as a personal/demo BYOK application.

The browser directly calls the OpenAI API using the API key supplied by the visitor.

Do NOT put your personal API key into the repository.

For a production/public application, route API requests through a backend and keep the API key server-side.
